# OpsSOP / Signal Archive

本版“信号档案”取代上一版森林绿外观。品牌采用工程档案的秩序与信号标记的对比，让故障证据、人工结论和知识资产拥有明确的阅读层级。

## 色彩

|角色|颜色|用途|
|---|---|---|
|信号橙|#C94B25|主要操作、当前对象与强调|
|石墨黑|#1C1E21|导航、品牌空间|
|暖纸白|#F2F0E9|工作底色|
|纸面|#FFFEFA|内容与表格|
|墨色|#232326|正文与标题|
|边线|#DEDBD2|结构分隔|

成功、警告、危险继续使用各自语义色，不能把品牌橙当作系统健康信号。工具栏和助手使用同一组语义色：成功 `#0B6B55`、警告 `#9B6713`、危险 `#B94742`、信息 `#436A9C`，各自配套浅底与边线。

## 构图与文字

工作台采用深色主题区、轨道式知识循环图形、连续数字指标带、带编号的知识目录及右侧任务栏。无待办时使用紧凑完成提示。指标及记录仍来自接口，不加入模拟趋势。

桌面导航保留 240px；移动视图收为抽屉。组件以 5–7px 小圆角、细边线、克制阴影组织。指标数字 54px，品牌标题 38–44px，正文 14px。小型技术标签使用系统等宽字。

登录采用石墨网格背景、暖纸色表单、三节点知识流程和信号橙标记；网格仅用于品牌区域，业务表格与正文保持干净。

## 样式分层

前端样式按职责拆分，页面不再依赖高权重覆盖层：

|文件|职责|
|---|---|
|`frontend/assets/design-tokens.css`|唯一变量来源：品牌、纸面、语义色、字阶、间距、圆角、投影、动效时长与缓动|
|`frontend/assets/design-tokens.json`|与 CSS 变量一一对应的机器可读版本|
|`frontend/src/style.css`|Tailwind 入口（基础重置与工具类）|
|`frontend/src/styles/base.css`|文档排版、焦点、选区、滚动条与跨页文字/标记工具类|
|`frontend/src/styles/element.css`|Element Plus 主题变量映射与组件结构样式|
|`frontend/src/styles/components.css`|页面骨架、面板、筛选条、空状态、加载失败等通用组件|
|`frontend/src/styles/motion.css`|路由切换、错峰入场、结果淡入、行悬停与 `prefers-reduced-motion`|

页面构图与响应式规则保留在各视图的 scoped 样式中，只引用上表变量。上一版 `signal.css` 覆盖层已删除；如新增外观，应扩展变量或通用组件，而不是再用 `#app` 前缀叠加选择器。

## 动效

|场景|时长|方式|
|---|---|---|
|导航悬停、按钮、输入焦点|140ms|`background-color` / `color` / `box-shadow` 过渡|
|路由进入|180ms|淡入 + 7px 上移；离开 120ms 只淡出|
|工作台首次入场|200ms / 错峰 40ms|指标与内容区依次 `opacity` + `translateY`，整组不超过 400ms|
|弹窗|220ms|轻微缩放（0.985→1）+ 淡入；遮罩淡入|
|抽屉|220ms|`transform` 平稳滑入/滑出|
|AI 结果|200ms|仅淡入与 3px 位移，不改变阅读位置|

规则：

- 首次入场与数据更新分开；输入、轮询或列表刷新不会让整块内容重新播放入场。
- 只用 `transition`、`transform`、`opacity`，不为动效引入依赖。
- 减少动态偏好下关闭位移、错峰与循环装饰，保留状态与提示可见。
- 动效不改变点击目标位置；保存、提交、分析均保留真实加载、失败与过期状态，并提供防重复提交保护。

## 文件与维护

`frontend/assets/design-tokens.json` 与 `design-tokens.css` 同步维护。图标为本地 SVG；不加载远程字体。

任何外观更新都应保留真实权限、业务状态、来源引用、模拟标识、用量未知和失败提示。
