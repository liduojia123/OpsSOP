- 页面标题使用统一基线和短橙色定位线；正文与控件字号、表格行距、面板和语义状态同步到设计变量。
- 工作台指标合为连续概览，并可跳转对应业务列表；待处理和审核继续优先展示。
- 故障、案例、SOP 的筛选与结果合为一个工作面，刷新保留已有记录，初次请求使用统一能量条与骨架，不误显空状态。
- 案例/SOP 正文和元数据统一间距，桌面侧栏可随阅读保持可见，窄屏回到单列；故障正文与 AI 助手保持独立滚动。
- AI 对话按可视区域分配空间，消息独立滚动、输入区固定在对话底部；手机会话栏默认收起，可展开搜索和切换历史。既有流式跟随逻辑保留。
- 监控图表、管理概览、审计筛选、弹窗及全局等待提示统一配色和尺寸；全局提示文字不再随能量 SVG 拉伸。没有新增依赖。

验证：21 个测试文件、105 项前端测试、类型检查与生产构建通过。Chromium 检查八个主业务页面的 1440px / 375px 布局及故障详情，无页面级横向溢出；实测关键词搜索返回、侧栏半隐藏、手机导航、会话栏展开/收起及故障/SOP 创建弹窗（仅打开和关闭）。浏览器未记录控制台错误。

限制：本轮未调用真实模型、未提交业务表单；测试数据没有案例和 SOP，因此这两类详情的真实有内容页面由既有组件测试覆盖，未在浏览器以新数据补测。Firefox/Safari 和系统级减少动态未重新实测。最终独立审查代理因用量限制未完成，已自行复查模板结构、展示层差异和回归结果。生产构建仍有既有 Element Plus 主包大于 500kB 的提示。

## 登录图形分割转场（2026-11-01）

登录加载反馈采用 320×24px 的细长能量条（窄屏按视口缩小），标题和百分比独立排在上方，以原生文字渲染，避免随 SVG 宽高拉伸。该比例调整仅作用于登录页。

点击登录后先显示品牌橙能量加载条，入场准备进度在三秒内从 0% 线性填到 100%，满格保留 150ms 后再进入图形动画。该百分比表示定时入场准备，不表示服务器验证进度；验证超过三秒时最多停在 99%，验证成功才填到 100%，不再重新等待三秒。验证失败立即提示，离开页面清理计时器与请求。准备完成后，仅以居中的现有橙色 S 图形和整张浅色背景覆盖画面，去掉文字标志。图形尺寸随视口在 240–420px 间缩放；切口结合图形内部两道斜向留白，以折线连接，背景和图形向左下、右上错开展开，露出工作空间。开门前短暂停留 220ms，展开 920ms。普通切页及刷新不重播，原有站内登录回跳保留。其他侧栏图标仍默认 44px。

转场期间背景使用 `inert` 禁止误操作，结束后恢复并将焦点交给工作区；可跳过动画。认证失败不播放，导航失败移除遮罩；路由等待和动画事件均有超时兜底，返回登录页或卸载时清理。减少动态模式直接淡入。

验证：101 项前端测试、类型检查、生产构建通过；受控时钟覆盖 0%、中点约 50%、三秒 100% 且尚未入场、满格停留后入场、慢验证 99% 等待及成功后 100%、重复提交、失败和离开页面。本机 Chromium 实际采样约 3.06 秒显示 100%，约 3.22 秒首次观察到转场，结束后遮罩与交互锁定均移除；另已采集到可见的 100% 满格截图。此前实际登录已采集到斜向折线分离及交互恢复；1280px 桌面的图形约 410px，375px 手机为 240px，手机无横向溢出。减少动态、跳过和异常导航由组件测试覆盖；Firefox/Safari 尚未验证。部署仍仅更新 `18081`，保留 `18080`。

## 能量加载参考版（2026-11-01）

依据用户提供的视频，将加载反馈改为能量填充：不规则波动前沿、局部辉光和少量微粒，仍使用浅色底板。配色按网站主题统一为品牌橙、暖白前沿与浅橙底板，成功/失败继续使用系统语义色。使用原生 SVG 与约 30fps 的 RAF 更新，不增加项目依赖。此节替代旧版预览对话框的电路加载演示说明，背景电路装饰继续保留。

- 顶部“动效预览”可调节演示进度、速度和波幅，播放成功或异常流程；百分比明确为演示。
- 实际 Axios 请求和工作台等待状态使用循环能量带；未知进度不显示百分比，仍按真实请求并发计数结束。
- 故障 AI 分析、案例 AI 生成 SOP 和对话首段回复等待自动显示局部能量条，绑定原有请求状态；结束、失败、取消或开始输出文字时收起。局部提示可见时隐藏重复的全局浮动卡片，顶部细线继续保留。关闭 SOP 抽屉时移除局部动画，由全局提示接管；重新打开仍可查看等待状态。
- 响应系统减少动态设置；后台页面暂停绘制，关闭演示或卸载组件后释放动画、监听与计时器。
- 95 项前端测试、类型检查和生产构建通过；三个自动入口使用受控请求测试，覆盖出现/收起、首段回复与关闭/重开抽屉。Chromium 实测品牌配色与预览显示。未调用真实模型；Firefox/Safari 尚未验证。此前能量组件的 375px 弹窗与加载条无横向溢出验证仍保留。

预览仍为本机 `18081`，账号和数据与原测试环境共用，`18080` 保留；未调用模型或修改业务记录。

## 动效

| 场景 | 实现 |
|---|---|
| 导航 | 背景与图标颜色 140ms 过渡；当前项橙色标记短促切换；移动端侧栏 220ms 滑入 |
| 路由 | `Transition` 淡入 + 7px 上移（180ms），离开 120ms 淡出；同组件换参数不重播 |
| 工作台 | 指标与内容区 40ms 错峰入场，200ms 完成，整组 ≤400ms；仅首次挂载播放 |
| 知识条目 | 悬停背景变暖、右侧箭头右移 3px；空状态改为紧凑完成提示 |
| 按钮/表单 | 悬停、按下、禁用反馈；输入焦点 1px 品牌边线 + 3px 柔光环；保存使用真实 loading 与轻提示 |
| 弹窗/抽屉 | 弹窗 0.985 缩放淡入、抽屉 `transform` 滑入，均 220ms；保留 Esc 关闭与焦点管理 |
| AI 助手 | 真实“分析中”状态；结果按分析 ID 淡入；不模拟思考过程、不伪造进度、不自动滚动 |
| 减少动态 | `prefers-reduced-motion` 下关闭错峰、位移、循环节点漂移与箭头位移 |

新增 `scripts/ui_visual_check.py`：Playwright + 系统 Chrome，自动检查上述动效的计算样式、连续操作、防重复保存、来源回跳、空/失败状态、横向溢出，并输出截图与 webm 录屏。

## 业务边界

接口、权限、路由、状态流转、来源引用、版本与审核操作保持不变。新增的仅是展示层错误提示、加载失败重试入口、重复提交保护（保存/提交/追加记录/确认解决）和可访问的禁用样式。案例来源直达页仍只读，不展示来源故障私有日志。
