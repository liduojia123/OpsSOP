# 统一检索

适用版本：3.5.0。

左侧「工作空间 → 搜索」（或直接访问 `/search`）可在一个入口同时检索故障、案例、SOP 与监控服务器。

## 检索范围与权限

| 类型 | 匹配字段 | 可见范围 |
|---|---|---|
| 故障 | 标题、描述、服务 | 运维仅本人；审核/管理员全部 |
| 案例 | 标题、症状、服务 | 运维：本人创建或已通过；审核/管理员全部 |
| SOP | 标题、症状、适用环境 | 运维：本人创建或已发布/历史/废弃；审核/管理员全部 |
| 服务器 | 名称、主机、承载服务、备注 | 运维：启用的服务器；审核/管理员：含停用 |

- 只搜索摘要字段，不搜索也不返回日志正文；
- 权限与各列表页一致，检索层不放宽；
- 无匹配如实返回空，不编造结果；
- 每类默认最多 8 条，页面显示总数；总数超过显示条数时标注“仅显示前 N 条”。

## 使用

- 输入关键词回车或点「搜索」；
- 顶部类型按钮可只保留故障、案例、SOP 或服务器（至少保留一种）；服务器结果直达监控页；
- 结果按类型分组，点击整行打开对应详情；
- 支持 `/search?q=504&types=fault,case` 直接打开或收藏；
- 关键词示例：504、磁盘、order-service、OOM。

## 与 AI 检索的区别

- 本页面向人工搜索，返回可直接跳转的实体摘要；
- AI 对话的知识引用仍只取已审核案例与已发布 SOP，并经后端引用校验；故障/案例/SOP/服务器等业务数据通过只读工具查询，`search_all` 工具复用本页同一套检索与权限。
