# 界面与动效

适用版本：3.7.2。全站采用浅色线条风格，品牌橙作为信号色；改动只涉及展示层，接口、权限、路由与状态流转不变。配色与标志规范见[品牌规范](brand-guidelines.md)。

## 主题

全站提供两套可选外观，在「个人资料 → 界面主题」或顶栏调色板按钮切换；选择立即生效并保存在当前浏览器，不写后端，也不改变数据、权限与状态流转。

| 主题 | 外观 | 来源 |
|---|---|---|
| 信号光（默认） | 浅色线条、白色侧栏、冷灰画布 | 3.7 起的统一界面 |
| 经典档案 | 石墨侧栏、暖纸画布、深色标题区、5–8px 小圆角 | `archive/frontend-classic` 分支（3.6 信号档案）的视觉 |

- 默认主题变量见 `frontend/assets/design-tokens.css`；经典档案在 `frontend/src/styles/themes/classic.css` 中通过 `html[data-theme="classic"]` 覆盖变量与外观，不复制视图。
- 首屏由 `frontend/public/theme-boot.js` 在样式加载前恢复主题（生产 CSP 不允许内联脚本），避免刷新时先闪默认主题；`frontend/src/theme.ts` 负责切换、持久化与挂载前恢复。
- 经典档案同时补充 3.7 新增组件：隐藏信号背景拓扑图，能量加载与顶部请求线改为暖纸底色与小圆角，登录入场沿用暖色纸面，侧栏收起仍可用；工作台深色标题区只在经典档案主题渲染 3.6 的标题、说明与知识循环图形。
- 新增功能或组件必须同时核对两套主题；只允许覆盖展示层，演示标识、失败提示、用量未知、权限说明等业务状态在两套主题下都必须保留。

## 视觉

- 浅色背景、白色面板与冷灰分隔线；页面标题使用统一基线和短橙色定位线。
- 正文、表格、面板与语义状态统一使用 `frontend/assets/design-tokens.css` 变量；图标为本地 SVG，不加载远程字体。
- 工作台指标合并为连续概览，可跳转对应列表；故障、案例、SOP 的筛选与结果合为一个工作面，刷新保留已有记录。
- 桌面侧栏可收起为图标栏，浏览器记住选择；手机端使用完整抽屉导航。
- 为窄屏保留单列布局；故障正文与 AI 助手各自独立滚动。

## 动效与反馈

- 背景与面板线条按信号节奏缓慢流动；悬停显示边线，输入聚焦显示品牌色下划线，按钮有按下反馈。
- 真实请求驱动：请求超过 120ms 显示顶部细进度线，全部请求结束后收束；列表和 AI 等待使用能量条与骨架，无可计算进度时不显示假百分比。
- 登录：能量条三秒从 0% 填到 100%（入场准备，不代表服务器验证）；成功后橙色 S 图形与背景沿折线错开进入工作空间。可跳过，`prefers-reduced-motion` 直接淡入。
- 对话流式回答持续跟随最新内容；用户上翻时暂停，回到底部 40px 内恢复。
- 后台页面暂停绘制；组件卸载后释放计时器、监听与动画。
