# 界面与动效更新（Signal Archive 第二版收尾）

本次在第二版“Signal Archive / 信号档案”方向内完成前端统一与交互动效补齐：清理两轮设计叠加的覆盖样式，建立分层样式与统一变量，覆盖全部 9 个路由及其加载、空、失败、保存中、审核、退回、历史版本状态，并逐页检查桌面与窄屏。

完整视觉定义见[品牌规范](brand-guidelines.md)。

## 样式整理

- 删除 `frontend/src/signal.css` 覆盖层；原先依赖 `#app .ops-*` 提升权重的规则，改为在页面 scoped 样式中使用变量，或在通用组件中定义一次。
- 样式职责拆分：`assets/design-tokens.css`（变量）、`src/style.css`（Tailwind 入口）、`styles/base.css`（排版与工具类）、`styles/element.css`（Element Plus 主题）、`styles/components.css`（面板/筛选/空状态/错误态）、`styles/motion.css`（动效与减少动态）。页面构图保留在各视图 scoped 样式中。
- 品牌文档、`design-tokens.json` 与 CSS 变量同步；新增纸面层次、语义浅底、代码面、动效时长等变量，页面中的重复十六进制色值收敛到变量或页面级局部值。
- 统一 Element Plus：按钮、输入/焦点环、表格、标签、弹窗、抽屉、轻提示、确认框、说明条、页签、下拉与加载遮罩。
- 修复第二版遗留问题：故障筛选条未横向排列、系统管理指标卡缺内边距、来源详情与 SOP 侧栏标题重复留白、环境标签溢出、纯色系统状态被品牌橙覆盖。

## 动效

| 场景 | 实现 |
|---|---|
| 导航 | 背景与图标颜色 140ms 过渡；当前项橙色标记短促切换；移动端侧栏 220ms 滑入 |
| 路由 | `Transition` 淡入 + 7px 上移（180ms），离开 120ms 淡出；同组件换参数不重播 |
| 工作台 | 指标与内容区 40ms 错峰入场，200ms 完成，整组 ≤400ms；仅首次挂载播放 |
| 知识条目 | 悬停背景变暖、右侧箭头右移 3px；空状态改为紧凑完成提示 |
| 按钮/表单 | 悬停、按下、禁用反馈；输入焦点 1px 品牌边线 + 3px 柔光环；保存使用真实 loading 与轻提示 |
| 弹窗/抽屉 | 弹窗 0.985 缩放淡入、抽屉 `transform` 滑入，均 220ms；保留 Esc 关闭与焦点管理 |
| AI 助手 | 真实“分析中”状态；结果按分析 ID 淡入；不模拟思考过程、不伪造进度、不自动滚动 |
| 减少动态 | `prefers-reduced-motion` 下关闭错峰、位移、循环节点漂移与箭头位移 |

新增 `scripts/ui_visual_check.py`：Playwright + 系统 Chrome，自动检查上述动效的计算样式、连续操作、防重复保存、来源回跳、空/失败状态、横向溢出，并输出截图与 webm 录屏。

## 业务边界

接口、权限、路由、状态流转、来源引用、版本与审核操作保持不变。新增的仅是展示层错误提示、加载失败重试入口、重复提交保护（保存/提交/追加记录/确认解决）和可访问的禁用样式。案例来源直达页仍只读，不展示来源故障私有日志。

## 验证结果（2026-10-28，本机）

- `npm.cmd run build`：通过；仍保留既有的大包体积提示（Element Plus 主包约 1.06MB，未拆分）。
- `npm.cmd test`：8 个测试文件、50 项通过（新增 1 项“保存请求在途时重复点击只提交一次”）。
- `scripts/ui_visual_check.py`：55/55 项通过，覆盖动效计算样式、减少动态、连续导航与切换页面后的滚动复位、重复保存、登录回跳、来源只读、列表失败、AI 失败与 1440/390 宽度横向溢出。
- 截图 33 张（自动采集 31 张：桌面 20（含审核视角 2）、窄屏 8、状态 3；长日志补充 2 张），录屏 1 段约 13s（webm）。
- 环境：独立演示数据库，`AI_MODE=demo`（显式模拟）、`EMBEDDING_MODE=disabled`、关键词检索；未调用真实模型，不代表模型质量。

截图、录屏与机器可读结果位于仓库外的本次交付目录；脚本可用 `UI_ARTIFACT_DIR` 指定输出位置。

## 尚未验证 / 剩余问题

- 仅在 Chromium（系统 Chrome）检查，未验证 Firefox/Safari 的动画一致性。
- 空状态、列表失败与 AI 失败通过拦截接口构造，用于界面状态检查，不代表真实故障注入。
- 系统管理的加载失败仍以轻提示呈现，没有像列表页一样常驻错误块；如需统一可后续补。
- 动效为手工与脚本断言检查，尚未加入截图对比式的视觉回归基线。
- 演示数据中的长文本有限，超长日志/超长标题只做了换行与溢出规则检查，未做大规模压力样本。
- 未执行后端权限、状态流转、真实模型或云部署验收，这些仍以后端测试与部署验证为准。
