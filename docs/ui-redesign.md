# 界面与动效

适用版本：3.7.1。全站采用浅色线条风格，品牌橙作为信号色；改动只涉及展示层，接口、权限、路由与状态流转不变。配色与标志规范见[品牌规范](brand-guidelines.md)。

## 视觉

- 浅色背景、白色面板与冷灰分隔线；页面标题使用统一基线和短橙色定位线。
- 正文、表格、面板与语义状态统一使用 `frontend/assets/design-tokens.css` 变量；图标为本地 SVG，不加载远程字体。
- 工作台指标合并为连续概览，可跳转对应列表；故障、案例、SOP 的筛选与结果合为一个工作面，刷新保留已有记录。
- 桌面侧栏可收起为图标栏，浏览器记住选择；手机端使用完整抽屉导航。
- 为窄屏保留单列布局；故障正文与 AI 助手各自独立滚动。

## 动效与反馈

- 背景与面板线条按信号节奏缓慢流动；悬停显示边线，输入聚焦显示品牌色下划线，按钮有按下反馈。
- 真实请求驱动：请求超过 120ms 显示顶部细进度线，全部请求结束后收束；列表和 AI 等待使用能量条与骨架，无可计算进度时不显示假百分比。
- 登录：能量条三秒从 0% 填到 100%（入场准备，不代表服务器验证）；成功后橙色 S 图形与背景沿折线错开进入工作空间。可跳过，`prefers-reduced-motion` 直接淡入。
- 对话流式回答持续跟随最新内容；用户上翻时暂停，回到底部 40px 内恢复。
- 后台页面暂停绘制；组件卸载后释放计时器、监听与动画。

## 验证（2026-11-02）

- 前端 21 个测试文件、105 项测试通过；`vue-tsc` 类型检查与生产构建通过。
- Chromium 检查 8 个主业务页面的 1440px / 375px 布局及故障详情，无页面级横向溢出，控制台无错误。
- 未验证 Firefox / Safari 与系统级减少动态；动效尚未加入截图对比式视觉回归。
- 生产构建仍有 Element Plus 主包超过 500kB 的提示。

旧版界面保留在 `archive/frontend-classic` 分支。
